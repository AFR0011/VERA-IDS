# Information Architecture

Start with `README.md`, then use `DATASETS.md` and `REPRODUCIBILITY.md` to
understand inputs/execution, `RESULTS.md` and `RESULTS_PROVENANCE.md` for evidence,
and `ERRATA.md`/`AUDIT_REPORT.md` for limitations. Top-level publication documents
are reader-facing. `docs/` contains workflow/method authorities; `docs/source/`
preserves historical source documents with staleness warnings. Internal audit CSVs
remain ignored under `.release-audit/`.
