# JISA main-text figure generation

This workflow generates the numerical main-text figures for the JISA manuscript from the frozen VERA-IDS result artifacts. It performs no training, model selection, threshold selection, or new inference.

Figure 1 is the non-numerical methodology/evaluation overview and is intentionally handled separately. Figures 2-11 are generated by the scripts below.

## Main workflow

From the repository root on branch `jisa-finalization`:

```bash
git checkout jisa-finalization
git pull
uv sync --locked
uv run python scripts/28_build_jisa_main_figure_sources.py
uv run python scripts/29_render_jisa_main_figures.py
```

The source-builder writes compact plotting tables and a SHA256 source manifest to:

```text
outputs/12_jisa_finalization/20_main_figure_sources/
```

The renderer writes each figure as editable SVG, vector PDF, and 300-dpi PNG to:

```text
outputs/12_jisa_finalization/21_main_figures/
```

## Required frozen artifacts

Most inputs are either committed compact summaries or local journal-final outputs already produced by the frozen experiment pipeline. In particular, Figure 4 requires:

```text
outputs/11_reference_framework_eval/comparison/protocol_b_holdout_stress_table.csv
```

If the reference-framework experiment outputs exist but the comparison tables are missing, rebuild only the comparison layer with:

```bash
uv run python scripts/11b_build_reference_framework_comparison.py
```

Figure 5 requires the recovered CICIDS2017 exact-duplicate audit containing:

```text
cross_split_exact_duplicate_audit.csv
split_hash_summary.csv
```

The default location is:

```text
q2_reproducibility_audit/
```

If those files are elsewhere, pass the directory explicitly:

```bash
uv run python scripts/28_build_jisa_main_figure_sources.py --recovered-overlap-root PATH_TO_AUDIT_DIRECTORY
```

If the recovered duplicate audit has not yet been materialized locally but the recovered processed Protocol-B surface exists at its frozen path, regenerate the audit with:

```bash
uv run python -m ids_eval_framework._native.audit_split_leakage
```

## Scientific boundaries

The plotting scripts preserve the frozen interpretation boundaries used in the manuscript:

- Published closed-set reference values and framework-compatible reference-profile runs are descriptive contrasts, not byte-identical third-party reproductions.
- Protocol-B reference-profile results are stress tests of literature-derived configurations; they do not imply that the cited papers evaluated held-out-family recognition.
- Exact processed-feature hash overlap does not establish repeated physical flows and does not quantify near-duplicates.
- CICIDS2017 partition-sensitivity changes are not attributed causally to duplicate removal because partition composition also changes.
- Known-versus-held-out family correlations use six families per dataset and are descriptive.
- Failure destinations describe model behavior and do not imply semantic equivalence among attack families.
- Rejection operating points are selected on validation only; test constraint exceedances are retained as out-of-sample results and are never used for reselection.

The older `scripts/26_build_jisa_figure_sources.py` and `scripts/27_render_jisa_figures.py` are retained as historical artifacts from the earlier five-figure manuscript plan. The journal-final main-text figure workflow is scripts 28-29.
