# Model Evaluation

Report Stage-1 binary metrics, Stage-2 fixed-K/present-family metrics, end-to-end
system metrics, direct baseline metrics, Unknown detection/false-unknown/coverage,
calibration, external stress, and seed variability separately. Macro-F1 requires
an explicit ordered label set. Unknown metrics are undefined without true Unknown
support. See `RESULTS.md`, `ERRATA.md`, and `src/ids_eval_framework/metrics.py`.
