# Compact Result Summaries

These path-free aggregate tables contain no benchmark rows, row-level scores, or
model binaries. `SOURCE_MANIFEST.csv` records every file's size, SHA-256, and
provenance description.

Protocol A summaries were deterministically regenerated from
`outputs/evidence/protocol_a_confusion_matrices.jsonl`; unaffected columns retain
their historical source values. See `RESULTS.md` and
`../../RESULTS.md` and `../../PROTOCOL_A_CORRECTION.md` for interpretation.
